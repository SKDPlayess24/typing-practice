    A. Publish directly (fastest)

    How to get a token (one time)
    1. On GitHub, open your profile picture menu, then Settings.
    2. At the bottom of the left menu choose Developer settings, then Personal access tokens, then Fine-grained tokens.
    3. Click Generate new token and give it any name.
    4. Under Repository access choose Only select repositories and pick typing-practice.
    5. Under Permissions, open Repository permissions and set Contents to Read and write.
    6. Generate the token, copy it and paste it above. Never share it with anyone.

    B. Download and upload yourself

    Download paragraphs.json, then on GitHub open your repository, choose Add file, Upload files, drop the file in and commit. It replaces the old one.
